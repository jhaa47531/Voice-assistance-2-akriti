Android-based personal AI voice assistant built using Kotlin and Jetpack Compose.
The project integrates multiple AI providers such as Gemini, Groq and OpenRouter, along with Speech-to-Text, Text-to-Speech, Hinglish voice processing and Android device actions. It supports smart command routing for tasks like WhatsApp, YouTube, phone calls, web search, alarms, timers, reminders, notes and device controls.
Current status: Remade version successfully builds through GitHub Actions and is undergoing real-device testing and refinement.
